# Apex Mechanical Dashboard

A clean, modern, mobile-friendly HVAC project management dashboard for Apex Mechanical.

## Features

- Customer tracking overview
- Service call tracking
- Preventive maintenance scheduling
- Quote tracking
- Invoice tracking
- Equipment history
- Technician notes
- Labor, material, and subcontractor cost tracking
- Interactive profit calculator
- Dark mode toggle
- Simple responsive navigation

## Run locally

```bash
npm run dev
```

Then open http://localhost:5173.

## Build

```bash
npm run build
```
